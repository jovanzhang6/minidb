# 页面布局设计文档

本文档详细定义了MiniDB中各类页面的字节布局，是数据持久化的核心规范。

## 1. 通用页面结构

所有页面大小固定为 **4096 字节**。

```
┌─────────────────────────────────────────┐  偏移 0
│                                         │
│              页面内容                    │
│           (根据页面类型不同)             │
│                                         │
└─────────────────────────────────────────┘  偏移 4095
```

## 2. 数据库文件头页（Page 0）

第0页包含数据库文件头和第一个系统表的B-tree根。

```
┌─────────────────────────────────────────┐  偏移 0
│         数据库文件头 (100 字节)          │
├─────────────────────────────────────────┤  偏移 100
│                                         │
│     系统表 B-tree 根页内容               │
│     (作为 TABLE_LEAF 页)                │
│                                         │
└─────────────────────────────────────────┘  偏移 4095
```

### 2.1 文件头字节布局

```
偏移    大小    字段                描述
────────────────────────────────────────────────────────────
0       16      magic               魔数 "MiniDB format 1\0"
16      2       page_size           页大小，固定 4096 (0x1000)
18      4       page_count          数据库文件总页数
22      4       first_free_page     空闲页链表头页号，0表示无
26      4       free_page_count     空闲页总数
30      4       schema_version      Schema版本，DDL操作时递增
34      4       user_version        用户自定义版本号
38      4       next_rowid          下一个可用的全局rowid
42      58      reserved            保留字段，填充0
────────────────────────────────────────────────────────────
总计: 100 字节
```

**魔数 (Magic Number)**:
```
字节: 4D 69 6E 69 44 42 20 66 6F 72 6D 61 74 20 31 00
文本: M  i  n  i  D  B     f  o  r  m  a  t     1  \0
```

## 3. B-tree 页面类型

### 3.1 页面类型标识

| 类型值 (1字节) | 名称 | 描述 |
|---------------|------|------|
| 0x02 | INDEX_INTERIOR | 索引B-tree内部页 |
| 0x05 | TABLE_INTERIOR | 表B-tree内部页 |
| 0x0a | INDEX_LEAF | 索引B-tree叶子页 |
| 0x0d | TABLE_LEAF | 表B-tree叶子页 |

### 3.2 B-tree 页面通用结构

```
┌─────────────────────────────────────────┐  偏移 0 (或100如果是Page 0)
│            B-tree 页头                  │
│         (8或12字节)                     │
├─────────────────────────────────────────┤
│         Cell 指针数组                    │
│    (每个指针2字节，从低地址向高增长)      │
├─────────────────────────────────────────┤
│                                         │
│            未分配空间                    │
│                                         │
├─────────────────────────────────────────┤
│         Cell 内容区域                    │
│      (从高地址向低地址增长)              │
├─────────────────────────────────────────┤
│            保留区域                      │
└─────────────────────────────────────────┘  偏移 4095
```

## 4. B-tree 页头格式

### 4.1 叶子页页头（8字节）

```
偏移    大小    字段                描述
────────────────────────────────────────────────────────────
0       1       page_type           页类型 (0x0a 或 0x0d)
1       2       first_freeblock     第一个空闲块偏移，0表示无
3       2       cell_count          页内Cell数量
5       2       cell_content_start  Cell内容区起始偏移，0表示4096
7       1       fragmented_bytes    碎片字节数
────────────────────────────────────────────────────────────
总计: 8 字节
```

### 4.2 内部页页头（12字节）

```
偏移    大小    字段                描述
────────────────────────────────────────────────────────────
0       1       page_type           页类型 (0x02 或 0x05)
1       2       first_freeblock     第一个空闲块偏移，0表示无
3       2       cell_count          页内Cell数量
5       2       cell_content_start  Cell内容区起始偏移，0表示4096
7       1       fragmented_bytes    碎片字节数
8       4       right_child         最右子页页号
────────────────────────────────────────────────────────────
总计: 12 字节
```

## 5. Cell 格式

### 5.1 Table Leaf Cell (表叶子页Cell, 0x0d)

存储表的实际数据行。

```
┌─────────────────────────────────────────┐
│  payload_size (varint)                  │  负载大小
├─────────────────────────────────────────┤
│  rowid (varint)                         │  行ID（主键）
├─────────────────────────────────────────┤
│  payload (bytes)                        │  记录内容
│    ┌─────────────────────────────────┐  │
│    │ header_size (varint)            │  │  头部大小
│    ├─────────────────────────────────┤  │
│    │ serial_type_1 (varint)          │  │  列1类型
│    │ serial_type_2 (varint)          │  │  列2类型
│    │ ...                             │  │
│    ├─────────────────────────────────┤  │
│    │ value_1 (bytes)                 │  │  列1值
│    │ value_2 (bytes)                 │  │  列2值
│    │ ...                             │  │
│    └─────────────────────────────────┘  │
├─────────────────────────────────────────┤
│  overflow_page (4 bytes, 可选)          │  溢出页号
└─────────────────────────────────────────┘
```

**溢出阈值**: 当 payload 超过 `(4096 - 35) = 4061` 字节时使用溢出页。

### 5.2 Table Interior Cell (表内部页Cell, 0x05)

用于B-tree内部节点的索引。

```
┌─────────────────────────────────────────┐
│  left_child (4 bytes)                   │  左子页页号
├─────────────────────────────────────────┤
│  rowid (varint)                         │  分隔键（rowid）
└─────────────────────────────────────────┘
```

### 5.3 Index Leaf Cell (索引叶子页Cell, 0x0a)

存储索引键。

```
┌─────────────────────────────────────────┐
│  key_size (varint)                      │  键大小
├─────────────────────────────────────────┤
│  key_payload (bytes)                    │  索引键内容
│    ┌─────────────────────────────────┐  │
│    │ header_size (varint)            │  │
│    │ serial_types... (varints)       │  │
│    │ values... (bytes)               │  │
│    │ rowid (最后一个值)               │  │
│    └─────────────────────────────────┘  │
├─────────────────────────────────────────┤
│  overflow_page (4 bytes, 可选)          │  溢出页号
└─────────────────────────────────────────┘
```

### 5.4 Index Interior Cell (索引内部页Cell, 0x02)

```
┌─────────────────────────────────────────┐
│  left_child (4 bytes)                   │  左子页页号
├─────────────────────────────────────────┤
│  key_size (varint)                      │  键大小
├─────────────────────────────────────────┤
│  key_payload (bytes)                    │  索引键内容
├─────────────────────────────────────────┤
│  overflow_page (4 bytes, 可选)          │  溢出页号
└─────────────────────────────────────────┘
```

## 6. Cell 指针数组

Cell指针数组位于页头之后，每个指针2字节，指向Cell内容在页内的偏移。

```
页头后立即开始:
┌────────┬────────┬────────┬────────┬─────┐
│ ptr[0] │ ptr[1] │ ptr[2] │ ptr[3] │ ... │
│ 2bytes │ 2bytes │ 2bytes │ 2bytes │     │
└────────┴────────┴────────┴────────┴─────┘

ptr[i] 的值是 Cell[i] 在页内的字节偏移量
Cell按键值排序，ptr数组维护有序性
```

## 7. 空闲块管理

### 7.1 Freeblock 结构

页内删除Cell后留下的空闲空间以链表形式管理。

```
┌─────────────────────────────────────────┐
│  next_freeblock (2 bytes)               │  下一个空闲块偏移，0表示末尾
├─────────────────────────────────────────┤
│  size (2 bytes)                         │  当前空闲块大小（含头部4字节）
├─────────────────────────────────────────┤
│  free space (size - 4 bytes)            │  可用空间
└─────────────────────────────────────────┘
```

### 7.2 碎片字节

小于4字节的空闲空间无法形成freeblock，计入`fragmented_bytes`字段。
当碎片超过阈值时触发页面整理（defragment）。

## 8. 空闲页链表

### 8.1 Freelist Trunk Page

当整个页面被释放时，加入空闲页链表。

```
┌─────────────────────────────────────────┐  偏移 0
│  next_trunk (4 bytes)                   │  下一个trunk页号，0表示末尾
├─────────────────────────────────────────┤  偏移 4
│  leaf_count (4 bytes)                   │  本trunk管理的叶子页数
├─────────────────────────────────────────┤  偏移 8
│  leaf_page_1 (4 bytes)                  │  空闲叶子页号1
├─────────────────────────────────────────┤
│  leaf_page_2 (4 bytes)                  │  空闲叶子页号2
├─────────────────────────────────────────┤
│  ...                                    │
└─────────────────────────────────────────┘

每个trunk页最多可存储 (4096-8)/4 = 1022 个叶子页号
```

## 9. 溢出页

当Cell的payload超过阈值时，超出部分存储在溢出页链表中。

```
┌─────────────────────────────────────────┐  偏移 0
│  next_overflow (4 bytes)                │  下一个溢出页号，0表示末尾
├─────────────────────────────────────────┤  偏移 4
│  payload_data (4092 bytes)              │  溢出数据
└─────────────────────────────────────────┘  偏移 4095
```

## 10. Varint 编码

变长整数编码，用于压缩存储整数。

### 10.1 编码规则

- 每字节的最高位(bit 7)是继续标志：1表示后续还有字节，0表示结束
- 每字节的低7位是数据位
- 大端序排列

### 10.2 编码示例

| 值 | 字节数 | 编码 |
|----|--------|------|
| 0 | 1 | 0x00 |
| 127 | 1 | 0x7F |
| 128 | 2 | 0x81 0x00 |
| 16383 | 2 | 0xFF 0x7F |
| 16384 | 3 | 0x81 0x80 0x00 |

### 10.3 解码伪代码

```cpp
uint64_t decode_varint(const uint8_t* data, int* bytes_read) {
    uint64_t result = 0;
    int shift = 0;
    int i = 0;
    while (i < 9) {
        uint8_t byte = data[i];
        if (i == 8) {
            result |= (uint64_t)byte << shift;
            i++;
            break;
        }
        result |= (uint64_t)(byte & 0x7F) << shift;
        if ((byte & 0x80) == 0) {
            i++;
            break;
        }
        shift += 7;
        i++;
    }
    *bytes_read = i;
    return result;
}
```

## 11. 页面操作示例

### 11.1 插入Cell

1. 计算Cell大小
2. 检查未分配空间是否足够
3. 若不足，尝试从freeblock分配或触发整理
4. 在Cell内容区写入Cell
5. 更新`cell_content_start`
6. 在指针数组插入新指针（保持有序）
7. 更新`cell_count`

### 11.2 删除Cell

1. 根据Cell指针找到Cell位置
2. 将Cell空间转为freeblock加入链表
3. 从指针数组删除对应指针
4. 更新`cell_count`
5. 累计碎片字节

### 11.3 页面整理 (Defragment)

1. 收集所有有效Cell
2. 从页尾重新紧凑排列
3. 更新所有Cell指针
4. 重置freeblock链表和碎片计数
